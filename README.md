# Replication Dataset: The Sharper the Edit, the Colder the Reception?

Replication dataset and feature documentation for the manuscript:
**"The Sharper the Edit, the Colder the Reception? An Authenticity-Threat Perspective on Proximity Tourism Short Videos on TikTok"**

## Data Summary
- **Domain**: Proximity tourism / marketplace-scene short videos on TikTok
- **Sample Size**: 23,010 videos
- **Variables**: Multi-dimensional spatial cues (embedded narrative, sensory polish, interaction guidance) and audience engagement metrics (plays, likes, comments, shares, collects).

## Files Description
- : Processed features used in negative binomial regressions and XGBoost/SHAP models.
- : Comprehensive codebook and variable dictionary.
- : Cleaned metadata sample.

## License and Ethical Use
The data are derived from publicly available platform metadata on TikTok and processed in accordance with academic research ethics and platform terms of service. Available for scientific reproduction and peer review.
